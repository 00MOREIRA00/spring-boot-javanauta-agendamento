# spring-boot-javanauta-agendamento
Repositório destinado a criação de um projeto Spring Boot


* `entity` - Pacote destinado a criação das entidades do projeto
* `repository` - Pacote destinado a criação dos repositórios do projeto
* `service` - Pacote destinado a criação dos serviços do projeto
* `controller` - Pacote destinado a criação dos controladores do projeto
